# Homebrew tap for Marfa

This tap holds the Homebrew formula for the [Marfa](https://github.com/withmarfa/marfa) command line, `marfa`.

## Install

The formula isn't published yet. After it ships, you install the command line with:

```sh
brew install withmarfa/tap/marfa
```

Progress is tracked in [withmarfa/marfa#2286](https://github.com/withmarfa/marfa/issues/2286).
